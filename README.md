# Логово — Слот-машина

Игра «Однорукий бандит» для Telegram-бота бара Логово.

## Как работает
- Гость открывает бота → жмёт «🎰 Сыграть»
- Запускается WebApp со слотом
- 1 прокрут в день
- При выигрыше — промокод для официанта

## Стек
- Чистый HTML/CSS/JS
- Telegram WebApp API
- Хостинг: GitHub Pages
